## ✨ Features

- [x] Bing browsing simulation using Playwright
- [x] Activity tracking and logging
- [x] Earning mechanism testing and analysis
- [ ] (Future) Customizable browsing parameters
- [ ] (Future) Data visualization and reporting


## 🚀 Quick Start

This project requires Node.js and npm (or yarn) to be installed.  Once installed, clone the repository and run:

```bash
git clone https://github.com/r47dzt3ch/Surf2Earn-Bing.git
cd Surf2Earn-Bing
npm install  # or yarn install
npm run start # or yarn start
```
